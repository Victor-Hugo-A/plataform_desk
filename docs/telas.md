# Telas do Sistema

## Login

Tela inicial para autenticação do usuário.

## Dashboard

Exibe resumo dos chamados, status, prioridades e indicadores operacionais.

## Chamados

Lista todos os chamados cadastrados.

## Novo Chamado

Formulário para abertura de nova solicitação.

## Categorias

Tela para cadastro e listagem de categorias.

## Usuários

Tela administrativa para consulta dos usuários cadastrados.
